# Riyad Portfolio

Frontend-only React portfolio.

## Tech
- React
- Vite
- React Router
- Framer Motion
- Markdown blogs with `gray-matter`

## Blog flow
Add a new markdown file in:

`src/content/blogs/`

Example frontmatter:

```md
---
title: "My Post"
date: "2026-05-20"
excerpt: "Short summary."
---
```

## Resume
Put the final PDF here:

`public/resume.pdf`

## Run
```bash
npm install
npm run dev
```
